# 中缝关键点模型（512 / 1024 输入）

本目录是可复制到 SoC-2025 `4-dewarp/4-dewarp/keypoints` 下的 PR 文件包，包含两种输入尺寸训练得到的最佳权重。未包含训练集、原始验证图像及训练过程中的中间 checkpoint。

## 文件

- `models/seam_pose_1024_best.pt`：1024 输入尺寸最佳权重，约 6.3 MB。
- `models/seam_pose_512_best.pt`：512 输入尺寸最佳权重，约 6.2 MB。

## 训练与验证

两版均为 YOLOv8n-pose 六关键点模型，训练 150 epochs，batch size 4，seed 0，验证集使用同一配置。以下 pose mAP50–95 为各自训练过程中最佳 checkpoint 的验证指标。中缝端点误差是在 218 张带中缝标注的验证图上计算，端点误差取两个中缝端点像素误差的均值，再除以标注框对角线；两版均未漏检。


| 指标                 | 输入 1024            | 输入 512                 |
| ------------------ | ------------------ | ---------------------- |
| 最佳 pose mAP50–95   | 0.94388（epoch 142） | **0.96299（epoch 145）** |
| 中缝端点误差中位数（框对角线归一化） | 0.01219            | **0.01087**            |
| 端点误差 P90           | **0.02207**        | 0.02289                |
| 端点误差 P95           | **0.02840**        | 0.03075                |
| 标注验证图漏检数           | 0/218              | 0/218                  |


512 的整体 pose mAP 和端点误差中位数更好；1024 的 P90/P95 尾部误差略低。最困难的近横向中缝案例两版都仍有明显方向预测错误（归一化误差约 0.404 和 0.438），所以这次训练没有解决该 BADCASE。结果来自同一验证集，不能替代独立测试集评估；推理速度未做基准测试。
